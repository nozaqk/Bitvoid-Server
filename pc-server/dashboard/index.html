Network topology

The ESP-12E provides the Wi-Fi access point. The PC runs the BitVoid application server and dashboard. Client devices connect to the ESP Wi-Fi and communicate with the PC server over the local network.

ESP-12EWi-Fi gateway
PC SERVERAPI · Database · Dashboard
CLIENT DEVICESAndroid · Desktop

The PC server checks the ESP protected status endpoint every 10 seconds. Configure matching ESP dashboard credentials in the PC server .env file to enable live telemetry. Missing credentials or an unreachable gateway are reported honestly.
